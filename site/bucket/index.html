토큰은 어떻게 만들죠?
  1. 새 토큰 만들기를 엽니다.
  2. Token name에 버킷리스트, Expiration은 1년 정도로 정합니다.
  3. Resource owner는 minpuu, Repository access는 Public repositories 그대로 둡니다.
  4. Account permissions → Gists를 Read and write로 켜고 Generate token을 누릅니다.
  5. 한 번만 보이는 github_pat_…를 복사해 위 칸에 붙여넣습니다.

간단한 대안은 classic 토큰에서 gist 하나만 체크하는 방법입니다(ghp_…). 이 토큰은 다른 곳에 쓰지 마세요.
