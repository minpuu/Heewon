# 템플릿 3. 허브(모아보기)

- **카테고리:** 모아보기
- **역할:** 내부 트래픽 분배. 한 명이 들어와서 여러 글을 보게 만든다
- **조건:** 링크할 개별 경험담이 **5편 이상** 쌓였을 때
- **분량:** 블록 5~8개, 블록당 3~5줄
- **벤치마킹 원형:** 「아는 사람만 챙기는 공짜 혜택들」

---

```
[제목] 홈판형: "취준생이 올해 챙긴 공짜 돈들", "20대가 모르고 지나치는 돈들"
  - 총액을 넣으면 더 강하다: "올해 챙긴 돈 합쳐보니 ○○만 원"

[대표 이미지] 블록 사진들로 만든 콜라주 (4~8장)

■ 도입 (2줄)
  - "최근 ○달 동안 챙긴 돈들을 정리해 봤다."

■ 블록 × 5~8  (블록마다 같은 형식)
  ├ [증거 캡처] 입금 문자 / 0원 화면 / 승인 화면
  ├ [실물·일상 사진] (있으면)
  ├ **혜택 이름 굵게** → 어떻게 받았는지 1줄 → 일상 장면 1줄 → 금액
  └ 👉 참고 포스팅: [개별 경험담 글 제목]

■ 총정리 [인포그래픽: bars 카드]
  - 항목별 금액과 합계

■ 마무리 (손글씨 느낌 한 줄 + 이모지)
  - "다음 달엔 또 뭘 챙길 수 있을까 😏"
```

## 운영 팁

- 새 개별 글이 생기면 허브 글에 블록을 추가하고, 총액과 제목 숫자를 업데이트합니다.
- 반응이 좋은 허브 글은 3~6개월 뒤 숫자를 갱신해서 새 글로 다시 발행합니다.
  (벤치마킹 블로그: "500만원어치" → "700만원어치")
