# 템플릿 1. 개별 경험담

- **카테고리:** 돈 챙긴 기록
- **역할:** 검색 유입 + 애드포스트, 허브 글이 링크할 "본문"
- **분량:** 본문 1,500~2,500자, 이미지 10~15장
- **벤치마킹 원형:** 「쿠팡에서 700만원어치 제품 공짜로 받은 비결」

---

```
[광고·제휴 표기] (해당 시에만, 맨 위)

[제목] 홈판형 또는 검색형 (style-guide.md 3장)

[대표 이미지] 결과가 한눈에 보이는 사진
  → 입금 문자, 수료증, 0원 화면, 받은 물건 모아 찍기

■ 도입 (3~5줄)
  - 내 상황 1줄: "막학기 등록금 고지서를 받고…"
  - 문제 1줄: "알고 보니 ○○를 안 하면 ○○만 원을 그냥 날리는 거였다."
  - 결과 예고 1줄: "결론부터 말하면 ○○만 원을 돌려받았다."
  - (검색 키워드를 이 문단에 자연스럽게 포함)

■ 한눈에 요약 박스 (인포그래픽 카드 1장 또는 인용구)
  - 대상 / 혜택(금액) / 신청 기간 / 신청처 / 걸린 시간

■ 내가 해당되는지 확인한 과정
  - 요건 2~4개를 체크리스트로 쓰고, 각 요건에 내 상황을 붙인다
  - [이미지] 요건 확인 화면 캡처
  - 기준일과 출처 표기

■ 신청 과정 (단계별, 단계마다 캡처 1장)
  1단계: 어디서 → [캡처]
  2단계: 무엇을 입력 → [캡처]
  3단계: 막혔던 곳과 해결법 → [캡처]  ★ 직접 해본 디테일
  - 각 단계에 일상 장면 한 줄 ("알바 끝나고 밤 11시에…")

■ 결과
  - [이미지] 입금 문자 / 승인 화면 / 실물
  - 정확한 금액, 걸린 기간
  - 체감 환산: "이 돈이면 ○○ ○개월치"

■ 놓치기 쉬운 점 3가지
  - 반려 사유, 기한, 중복 불가 조건 등
  - (factcheck.md 기준으로 확인한 내용만)

■ 마무리
  - 1인칭 한 줄
  - **굵은 글씨 질문**
  - 👉 참고 포스팅: [관련 글 1~2개]

[태그] 핵심 키워드 3 + 대상 키워드 2 + 시즌 키워드 1~2
```

## 작성 전 체크

- [ ] 증거 캡처가 단계마다 있는가 (개인정보 가림)
- [ ] 직접 해본 디테일이 3개 이상인가
- [ ] 금액·요건·기한에 기준일과 출처가 있는가
- [ ] persona.md와 충돌하는 내용이 없는가
