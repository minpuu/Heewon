# 팩트체크 가이드

경제 정보 블로그에서 숫자 하나 틀리면 글 전체의 신뢰가 무너집니다.
발행 전 아래 순서로 확인합니다.

## 발행 전 체크리스트

- [ ] 모든 **금액**(지원금, 한도, 공제율, 금리)을 공식 출처에서 확인했다
- [ ] 모든 **요건**(나이, 소득, 재산, 주거)을 확인했다
- [ ] 모든 **기한**(신청 기간, 마감일, 기준일)을 확인했다
- [ ] 본문에 **기준일**을 적었다 — "(2026년 ○월 기준, ○○ 안내)"
- [ ] 출처가 블로그·카페·뉴스 2차 인용이 아니라 **기관 원문**이다
- [ ] 연도가 바뀌는 제도(지원 금액, 공제 한도)는 **올해 기준**인지 다시 봤다
- [ ] "누구나", "무조건" 같은 단정 표현이 없다
- [ ] 개인정보를 모두 가렸다

## 오류를 발견했을 때

1. 바로 수정하고 글 맨 위에 "○월 ○일: ○○ 금액을 정정했습니다" 한 줄
2. 같은 내용을 쓴 다른 글(허브 글 포함)도 함께 수정
3. 댓글로 지적받았다면 감사 답글
