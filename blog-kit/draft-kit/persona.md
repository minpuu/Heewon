# 페르소나 시트

모든 글의 "나"는 같은 사람이어야 합니다. 독자는 글 여러 개를 읽으면서 앞뒤가 맞는지 봅니다.
**빈칸을 실제 내 상황으로 채우고**, 상황이 바뀌면 날짜와 함께 기록합니다.

## 기본 정보

| 항목 | 내 상황 | 메모 |
|---|---|---|
| 나이대 | 20대 중반 | 정확한 나이는 안 밝혀도 됨 |
| 현재 신분 | 예: 대학 4학년 / 취준생 / 사회초년생 | |
| 소득 형태 | 예: 프리랜서 알바(3.3%) / 근로소득 / 없음 | |
| 주거 | 예: 자취(독립 세대주) / 부모님과 거주 | 세법상 판단에 영향이 큼 |
| 가족 | 예: 부모님 맞벌이, 동생 1명 | |
| 통신사 | 예: 알뜰폰 ○○ | |
| 보유 금융상품 | 예: 청년 주택드림 청약통장, 파킹통장 | |
| 블로그에서 쓰는 호칭 | 예: "나", 부모님은 "엄마 아빠" | |

## 충돌 체크리스트

글을 쓰기 전에 아래 조합이 같은 해(소득연도)에 겹치지 않는지 확인합니다.

- [ ] **부모님 연말정산 부양가족 등록** ↔ **본인 근로장려금 단독가구**
  - 부양가족(기본공제)이 되려면 연 소득금액 100만 원 이하(근로소득만 있으면 총급여 500만 원 이하)여야 합니다.
  - 근로장려금은 주민등록상 가구(그해 6월 1일 기준)로 봅니다.
  - 둘 다 해당될 수는 있지만, 글에서 "어떻게 둘 다 되는지"를 설명해야 독자가 의심하지 않습니다.
- [ ] **"자취생"** ↔ **부모님 주소에 같이 등록된 상태**
- [ ] **"취준생"** ↔ **"직장인" 표현**이 같은 시기 글에 섞이지 않는지
- [ ] 글마다 나오는 금액(월급, 알바비, 고정비)이 서로 맞는지
